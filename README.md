# Sound Design Portfolio Landing Page

A single-page static portfolio built with HTML, CSS, and JavaScript. It includes:

- Hero section with audio and video portfolio focus
- Embedded YouTube demo reel
- HTML audio controls for sound demos
- Project cards with video and audio links
- Responsive layout for desktop and mobile

## Deploy to Netlify

1. Push this repository to GitHub.
2. Sign in to Netlify and choose "New site from Git".
3. Select the GitHub repo and deploy.

Alternatively, deploy directly by dragging the project folder into Netlify Drop:

- https://app.netlify.com/drop

### Optional `netlify.toml`

A plain HTML site does not require a build step, but you can add a `netlify.toml` file with:

```toml
[build]
publish = "."
```

## Local preview

Open `index.html` in your browser or use a dev server like Live Server.
